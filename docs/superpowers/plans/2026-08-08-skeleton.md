# SpiderHub 工程骨架（A）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地可安装的 `spiderhub` 空壳包：目录齐全、CLI 占位、`ruff`/`mypy`/`pytest` 可跑。

**Architecture:** 手写 `src/` 布局 + hatchling；标准库 `argparse` CLI；子包仅 `__init__.py` 占位，无抓取逻辑。

**Tech Stack:** Python ≥3.11、`uv`、hatchling、ruff、mypy、pytest、pytest-asyncio；系统依赖仅通过 `brew` 安装。

## Global Constraints

- Python `>=3.11`；包名 `spiderhub`；入口 `spiderhub = "spiderhub.cli:main"`
- 运行时依赖：无；不引入 Scrapy / Typer / Click / httpx / Playwright
- 系统级工具只可用 `brew` 安装；失败则停并通知用户，禁止 `curl | sh` 等旁路
- Python 包装依赖只用 `uv` + `pyproject.toml`
- 提交生成的 `uv.lock`；不提交 `.env`
- 规范来源：`docs/superpowers/specs/2026-08-08-skeleton-design.md` 与根目录 `AGENTS.md`

- [ ] **Step 3: 实现 `src/spiderhub/cli.py`**

```python
from __future__ import annotations

import argparse
import sys
from collections.abc import Sequence


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="spiderhub")
    sub = parser.add_subparsers(dest="command", required=True)

    sub.add_parser("list", help="List registered spiders")

    run = sub.add_parser("run", help="Run a spider")
    run.add_argument("name", help="Spider name")
    run.add_argument(
        "--dry-run",
        action="store_true",
        help="Parse and validate without executing side effects",
    )
    return parser


def main(argv: Sequence[str] | None = None) -> int:
    parser = build_parser()
    args = parser.parse_args(list(argv) if argv is not None else None)

    if args.command == "list":
        print("No spiders registered yet.")
        return 0

    if args.command == "run":
        mode = " (dry-run)" if args.dry_run else ""
        print(
            f"spiderhub run {args.name}{mode}: not implemented",
            file=sys.stderr,
        )
        return 2

    parser.error(f"unknown command: {args.command}")
    return 2


if __name__ == "__main__":
    raise SystemExit(main())
```

说明：`list` 文案含 `No spiders registered` 即可通过测试；`run` 错误信息必须同时含 spider 名、`not implemented`，dry-run 时另含 `dry-run`。
